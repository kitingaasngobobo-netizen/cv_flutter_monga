## Description
Cette application présente mon CV de manière interactive :

- Mes compétences en Flutter, Dart, HTML, CSS
- Mon parcours et mes projets
- Page de contact

## Technologies utilisées

- VS Code
- Git & GitHub

## Comment lancer le projet

flutter pub get
